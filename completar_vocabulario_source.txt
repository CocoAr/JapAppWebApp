# Completar Vocabulario - fuente de datos para implementación

Origen: machete_vocabulario_japones_l1_l8_actualizado.pdf.
Uso: pegar este archivo en el repo para que el coding agent cree el tercer botón independiente "Completar Vocabulario".
Incluye: secciones 1 a 8 como ejercicios y sección 10 como consejos/asociaciones.
Excluye explícitamente: sección 9 "Frases armadas comunes" y sección 11 "Práctica intensiva: español -> japonés".

Formato TSV. Separador: tabulador. Codificación: UTF-8.
Columnas:
type	section	theme_id	item_id	japanese	spanish_prompt	accepted_japanese	prompt_note	hint	kana_mode	tags

Notas para el agente:
- En ITEM, japanese es la respuesta principal esperada. accepted_japanese lista variantes válidas separadas por punto y coma.
- Si accepted_japanese está vacío, aceptar solo japanese como exacto, además de tolerancias de scoring.
- En TIP, no hacer quiz: mostrar como contenido de consejos/asociaciones.
- Para ítems con 〜, aceptar con o sin 〜 cuando esté indicado.
- En preguntas/frases, comparar ignorando espacios y puntuación final japonesa cuando sea razonable.
- kana_mode es orientativo: hiragana, katakana, mixed, latin u other.
